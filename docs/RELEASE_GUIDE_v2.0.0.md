# Baseball Analyzer ver 2.0.0 リリース ＆ 総合運用ガイド

本ドキュメントは、**「Baseball Analyzer ver 2.0.0」** の正式公開に伴う新機能（投手分析・体組成分析・UI機能改善・セキュリティ安全策）を1つにまとめた総合取扱マニュアルおよびリリースノートです。

---

## 1. ver 2.0.0 主な新機能一覧

### ⚾ 1-1. 投手分析機能（Rapsodo Pitching）
「投手分析」モジュールでは、Rapsodo等の投球計測機器から出力されたCSVを読み込み、投手個人の各種スタッツや投球傾向をビジュアル分析できます。

- **投球データのCSVアップロード＆クラウド保存**:
  - 日本語・英語ヘッダー（`Pitch Speed`, `Spin Rate`, `VB (trajectory)`, `HB (trajectory)`, `球速`, `回転数`, `縦変化量` 等）を自動認識。
- **球速 (km/h) / 回転数 (rpm) / 縦横変化量 (VB / HB) 散布図**:
  - ピッチムーブメント（縦変化 vs 横変化）の視覚的プロット。
- **リリースポイントの一貫性**:
  - Release Height (高さ) / Release Side (横位置) のバラつき分析。
- **打者対戦成績・投球傾向**:
  - 球種割合およびカウント別配球傾向の集計・グラフ表示。

---

### 💪 1-2. 体組成分析機能（Body Composition）
「体組成分析」モジュールでは、選手の身体組成データを追跡し、パフォーマンス向上やフィジカル強化をサポートします。

- **FFMI（除脂肪重量指数）の自動計算・評価**:
  - 体重と体脂肪率からアスリート基準のFFMI（除脂肪重量指数）および身長180cm補正FFMIを自動計算し、フィジカルレベル（標準 / 良好 / 優秀 / プロ級）を判定。
- **部位別筋肉量バランス分析**:
  - 体幹・左右腕・左右脚の筋肉量をグラフ表示。左右バランス（左腕 vs 右腕、左足 vs 右足）を自動チェック。
- **多様なCSV・2行ヘッダーの自動認識**:
  - TANITAやInBody等の測定機器から出力される「1行目：部位大分類、2行目：部位小分類」の2行ヘッダー構成CSVも全自動でパース。
- **時系列推移グラフ**:
  - 体重・筋肉量・体脂肪率の増減トレンドを可視化。

---

### 🎨 1-3. 画面左上のカラーテーマ切替機能（昼 ☀️ / 夜 🌙 モード）
- **屋外・室内での視認性向上**:
  - 画面左上のロゴ横にあるボタンを押すことで、太陽光の下で見やすい「ライトモード（昼 ☀️）」と落ち着いた「ダークモード（夜 🌙）」をワンタッチで切り替え可能です。

---

### 📁 1-4. データ読み込み画面のレイアウト最適化
- **操作性の向上**:
  - 最も使用頻度が高い `1ファイル統合データ` を画面最上部に配置。
  - `Rapsodo 打撃データ (Hitting)` および `Blast Data (バット計測)` を下部に再配置し、現場での選択ミスを防止します。

---

### 🔒 1-5. アカウントセキュリティ強化（端末再起動時の自動ログアウト安全策）
- **安全セッション構造（sessionStorage）**:
  - PCやスマートフォンの**電源再起動**時、または**ブラウザアプリの完全終了・タブの削除**時には自動的にログインセッションが破棄されます。
  - 次回アクセス時には必ずログイン画面が表示されるため、グラウンド等での共用端末でも安全に運用可能です。
  - ※ タブを開いたまま画面を一時的にバックグラウンドにしただけの場合は、そのままログイン状態が保持されます。

---

## 2. CSV読み込み・運用のながれ

1. 左メニュー **「データ読み込み」** を開きます。
2. 目的のカード（1ファイル統合 / 体組成 / Rapsodo 投球 / Rapsodo 打撃 / Blast）で「ファイルを選択」をクリックします。
3. CSVファイル選択後、ブラウザ内で即時に自動パース・分析が行われます。
4. **「クラウド同期」** ボタンをクリックすると、各アカウント専用の安全なクラウド保存領域に保管されます。
