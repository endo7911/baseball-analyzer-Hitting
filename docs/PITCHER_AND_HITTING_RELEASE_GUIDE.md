# フェーズ1：投手分析機能リリース ＆ システム改修マニュアル (ver 1.1.0)

本ドキュメントは、**「ver 1.1.0：投手分析機能の先行公開」** に伴う新機能の使い方、および同時に適用された操作性改善・端末再起動時の安全対策についての一般ユーザー向け解説ガイドです。

---

## 1. 投手分析機能（Rapsodo Pitching）の使い方

「投手分析」モジュールでは、Rapsodo等の投球計測機器から出力されたCSVを読み込み、球速・回転数・変化量・リリースポイント等をビジュアル分析できます。

### 1-1. 投球データのアップロード
1. 左メニュー **「データ読み込み」** を開きます。
2. **「Rapsodo 投球データ (Pitching)」** の枠で 「ファイルを選択」 をクリックし、投球CSV（またはテスト用サンプルデータ）を選択します。
   - ※ 日本語・英語ヘッダー（`Pitch Speed`, `Spin Rate`, `VB (trajectory)`, `HB (trajectory)`, `球速`, `回転数`, `縦変化量` 等）を自動認識します。
3. アップロード完了後、**「クラウド同期」** ボタンを押すことで各アカウント専用のクラウド領域に安全にバックアップ保存されます。

### 1-2. 投手分析画面での分析項目
左メニュー **「投手分析」** をクリックすると、以下の分析ビューが利用できます。

- **投手サマリー / 選手切替**: チーム内の投手一覧から分析対象を切り替え可能。
- **球種別平均スタッツ**:
  - 平均球速 (km/h) / 最高球速
  - 平均回転数 (rpm)
  - 変化量：縦変化（VB / Vertical Break）、横変化（HB / Horizontal Break）
  - 縦横変化量散布図（Pitch Movement Chart）
- **リリースポイントの一貫性**:
  - Release Height (高さ) / Release Side (横位置) のバラつき分析
- **打者対戦成績・投球傾向**:
  - 球種割合（円グラフ/棒グラフ）およびカウント別の配球分析

## 2. ver 1.1.0 で適用された操作性・デザイン・安全策の改修点

投手機能の公開に合わせて、以下の機能・操作性改善が行われています。

### 2-1. 画面左上のカラーテーマ切替（昼 ☀️ / 夜 🌙 モード）
- **機能**: 左上ロゴ横のボタンを押すことで、屋外の太陽光の下で見やすい「ライトモード（昼 ☀️）」と、落ち着いた視認性の「ダークモード（夜 🌙）」をワンタッチで切り替え可能です。

### 2-2. データ読み込み順序の再配置
- **主な改善**: よく使う `1ファイル統合データ` を最上部に配置し、`Rapsodo 打撃データ (Hitting)` および `Blast Data (バット計測)` を下部に配置しました。
- **目的**: 現場でのファイル選択ミスの防止とスムーズな読み込み手順の確保。

### 2-3. アカウントセキュリティ強化（端末再起動時の安全対策）
- **安全対策の導入**: ログイン状態の保持先を `sessionStorage` に変更しました。
- **挙動**:
  - PCやスマートフォンの**電源再起動**時、または**ブラウザアプリの完全終了・タブの削除**時には自動的にログインセッションが破棄されます。
  - 次回アクセス時には必ずログイン画面が表示されるため、グラウンド等での共用端末でも安全に運用できます。
  - ※ タブを開いたまま画面を一時的にバックグラウンドにしただけの場合は、ログイン状態がそのまま維持されます。

## 3. 機能ON/OFF設定方法

環境変数（`src/config.js`）にて以下のように制御されています。

- `SHOW_PITCHER_MODULE`: `true`（投手分析モジュールを有効化 - ver 1.1.0）
- `SHOW_BODY_COMP_MODULE`: `false`（体組成分析モジュールは ver 1.2.0 にて有効化）
